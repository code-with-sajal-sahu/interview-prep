# Check Whether a Number Is Prime

## Problem Description

Write a Java program that takes an integer as input from the user and determines whether it is a prime number.

A **prime number** is a natural number greater than 1 that has exactly two distinct positive divisors: 1 and itself.

If the number has more than two positive divisors, or if it is less than 2, it is not a prime number.

## Input Format
- The input contains a single integer `n`.

## Output Format
Print `Prime` if the number is prime; otherwise, print `Not Prime`.

## Example 1

**Input**
```text
Enter an integer: 7
```

**Output**
```text
7 is Prime
```

## Example 2

**Input**
```text
Enter an integer: 10
```

**Output**
```text
10 is Not Prime
```

## Example 3

**Input**
```text
Enter an integer: 1
```

**Output**
```text
1 is Not Prime
```

## Example 4

**Input**
```text
Enter an integer: 2
```

**Output**
```text
2 is Prime
```

## Concepts Covered
- User input using `Scanner`
- Conditional statements (`if-else`)
- Loops (`for`)
- Modulo (`%`) operator
- Boolean variables
- Prime number logic

## Time Complexity
O(n)

## Space Complexity
O(1)
